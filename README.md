# Data Structures and Algorithms in C

This repository is my step-by-step journey to learn **Data Structures and Algorithms (DSA)** using the C programming language, from programming fundamentals to advanced problem solving.

## Goals

- Build a strong foundation in C and computational thinking.
- Understand how data structures work internally.
- Analyze time and space complexity for every solution.
- Implement algorithms from scratch without depending on built-in data structures.
- Solve problems consistently and improve code quality.

## Learning Roadmap

### 1. C Programming Fundamentals

- C syntax, variables, constants, and data types
- Input and output with `printf` and `scanf`
- Operators and expressions
- Conditional statements and loops
- Functions, scope, and recursion basics
- Arrays and strings
- Pointers and pointer arithmetic
- Structures, unions, enumerations, and `typedef`
- Dynamic memory allocation with `malloc`, `calloc`, `realloc`, and `free`
- File handling and basic error handling
- Compiling, debugging, and writing readable C programs

**Practice:** Build small programs such as a calculator, number analyzer, string utility, and student record manager.

### 2. Problem-Solving Foundations

- Breaking a problem into smaller steps
- Writing pseudocode and flowcharts
- Dry-running code with sample inputs
- Best-case, average-case, and worst-case analysis
- Big O, Big Theta, and Big Omega notation
- Time-space trade-offs
- Basic mathematical tools: logarithms, factors, primes, GCD, and modular arithmetic

**Practice:** Solve basic array, string, mathematics, and simulation problems.

### 3. Basic Data Structures

- Arrays and dynamic arrays
- Strings and character arrays
- Linked lists
	- Singly linked lists
	- Doubly linked lists
	- Circular linked lists
- Stacks using arrays and linked lists
- Queues using arrays and linked lists
- Circular queues and deques
- Hash tables and collision handling

**Practice:** Implement every structure from scratch with operations such as insert, delete, search, update, and display.

### 4. Searching and Sorting

**Searching**

- Linear search
- Binary search
- Binary search on the answer
- Searching in rotated and nearly sorted arrays

**Sorting**

- Bubble sort
- Selection sort
- Insertion sort
- Merge sort
- Quick sort
- Heap sort
- Counting sort
- Radix sort

**Practice:** Compare the algorithms by time complexity, memory usage, stability, and practical performance.

### 5. Recursion and Backtracking

- Recursion fundamentals and call stacks
- Base cases and recursive state
- Divide-and-conquer thinking
- Generating subsets and permutations
- Combination problems
- N-Queens
- Rat in a maze
- Sudoku solver
- Word search

**Practice:** Draw the recursion tree for each problem and identify repeated work.

### 6. Trees and Heaps

- Binary trees and tree terminology
- Preorder, inorder, postorder, and level-order traversal
- Binary search trees
- Tree height, depth, and diameter
- Lowest common ancestor
- Balanced trees and AVL tree rotations
- Heaps and priority queues
- Heapify and heap sort
- Trie data structure

**Practice:** Build a menu-driven tree toolkit and test it with different insertion orders.

### 7. Graph Algorithms

- Graph terminology and representations
- Adjacency matrices and adjacency lists
- Breadth-first search (BFS)
- Depth-first search (DFS)
- Connected components
- Cycle detection
- Topological sorting
- Bipartite graph checking
- Shortest paths: Dijkstra, Bellman-Ford, and Floyd-Warshall
- Minimum spanning trees: Prim and Kruskal
- Disjoint Set Union (Union-Find)

**Practice:** Solve grid, network, dependency, and route-planning problems.

### 8. Greedy Algorithms

- Greedy-choice property
- Activity selection
- Fractional knapsack
- Job sequencing
- Huffman coding
- Interval scheduling and merging
- Minimum coins and other greedy patterns

**Practice:** For each solution, explain why the local choice leads to a globally optimal result.

### 9. Dynamic Programming

- Identifying overlapping subproblems
- Optimal substructure
- Memoization and tabulation
- One-dimensional and two-dimensional DP
- 0/1 knapsack
- Coin change
- Longest common subsequence
- Longest increasing subsequence
- Edit distance
- Matrix chain multiplication
- Interval and tree DP
- Bitmask DP basics

**Practice:** Convert recursive solutions into memoized and tabulated versions, then compare their complexity.

### 10. Advanced Topics

- Bit manipulation and bitmasking
- Advanced hashing
- Segment trees
- Fenwick trees (Binary Indexed Trees)
- Sparse tables
- Advanced string algorithms: KMP, Z algorithm, and Rabin-Karp
- Network flow basics
- Strongly connected components
- Meet-in-the-middle
- Randomized algorithms
- Amortized analysis

### 11. Projects and Consolidation

- Command-line contact manager using linked lists and file handling
- Expression evaluator using stacks
- Priority-based task scheduler using heaps
- Autocomplete system using a trie
- Maze solver and shortest-path visualizer
- Graph-based route planner
- Mini search engine using indexing and string algorithms

## How I Will Study

For each topic, I will:

1. Learn the underlying idea and identify real-world use cases.
2. Analyze the time and space complexity.
3. Implement the data structure or algorithm in C from scratch.
4. Test normal, boundary, empty, and invalid inputs.
5. Solve practice problems without looking at the solution first.
6. Review mistakes and rewrite unclear or inefficient code.
